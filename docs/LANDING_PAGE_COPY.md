documentation to stay grounded in actual source code — not drift into a stale,

AI generation uses your own provider key — no platform lock-in, no hidden costs.

## How It Works

1. Connect source
   Connect GitHub or upload a ZIP. Repository Analysis produces one immutable
   snapshot that every Document in the Project shares — languages, endpoints,
   file structure, dependencies, and complexity. Progressive reveal means you
   see facts as they complete.

2. Shape the Outline
   Choose a Template or create a Custom Outline. Templates are recommended
   based on your documentation purpose and actual repository facts. Review,
   rename, reorder, or remove Sections before approving the active structure.

3. Generate and review
   Generate prose with your active provider or write manually. Every Section
   starts as a draft. Edit, accept, or regenerate — reviewed Sections record
   the supporting source snapshot and can later be flagged as potentially
   stale when evidence changes.

Provider-aware AI:

Freshness without overwrites:

changes. Pagemark explains what changed and lets you decide — update,
regenerate, or leave as-is. Reviewed content is never silently overwritten.

## FAQ

Do I need an AI provider to use Pagemark?
  No. Static Analysis and rule-based Template recommendations work without any
  provider credential. AI-personalized recommendations, Outline adaptation, and
  prose generation use your own provider account — you choose when to enable
  them.

Can I start without connecting source code?
  Yes. Create a blank Project and write documentation from scratch.
  Source-connected features — Template recommendations, evidence references,
  freshness tracking — only become available once you connect.

How does the multi-Document model work?
  One Project holds a shared Analysis snapshot. Each Document picks the
  relevant facts, chooses its own Template or Outline, and manages its own
  generation, review, and freshness lifecycle independently.

What happens when my source code changes?
  Pagemark flags reviewed Sections as potentially stale and explains what
  changed. It never overwrites reviewed content without your explicit action —
  you decide whether to update, regenerate, or leave the Section as-is.

How are AI costs handled?
  All AI actions use your own provider credential (Claude, Google AI Studio,
  etc.). You see estimated token usage and approximate cost before generation
  starts. Pagemark never charges for inference.

Can I export my documentation?
  Yes. Export single Documents as Markdown, styled HTML, or print-ready PDF.
  Branding, logo, headers, footers, and page layout are configurable.
