# Pagemark Landing Page Copy

## Positioning

Pagemark is a calm developer workspace for turning source code into structured technical documentation that maintainers review section by section.

It is for project maintainers who want documentation to be grounded in repository facts, shaped by a clear documentation purpose, and kept reviewable as the codebase changes.

## Hero

Headline:
Documentation that keeps pace with your codebase.

Supporting copy:
Pagemark analyzes your repository, recommends the right documentation structure, and helps you generate reviewable Section drafts from your own AI provider key.

Primary CTA:
Start a Project

Secondary CTA:
Sign in

Trust note:

## Product Proof

Panel title:
From repository facts to reviewed Sections

Workflow items:
- Analysis captures languages, file structure, endpoints, dependencies, and complexity as a reusable Project snapshot.
- Templates turn a documentation purpose into a concrete Outline that maintainers can edit before generation.
- Generated prose starts as a draft until a maintainer explicitly accepts the current Section content.

## Value Props

Source-grounded setup:
Start with repository facts instead of a blank page. Pagemark uses Analysis snapshots to recommend Templates and adapt Outlines to the actual project.

Reviewable generation:
Generate the complete Document or work Section by Section. Every generated Section remains a draft until reviewed and accepted.

Provider-aware usage:
Pagemark estimates provider usage before generation and records run-level and Section-level usage after generation.

Freshness workflow:
Reviewed Sections can later be flagged as potentially stale when source evidence changes, without overwriting accepted content.

## How It Works

1. Connect source
   Connect GitHub, upload a ZIP, or start without source. Repository Analysis produces reusable facts for the Project.

2. Shape the Outline
   Choose a Template or create a Custom Outline. Review the proposed Sections before they become the active Document structure.

3. Generate and review
   Generate prose with your active provider, edit drafts, and explicitly accept content when it is ready.
